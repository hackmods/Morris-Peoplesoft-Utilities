# Private pillar specialist templates

- [HCM](hcm/SKILL.md): workforce/position, payroll/time, benefits/absence and recruiting questions.
- [FSCM](fscm/SKILL.md): AP/procurement, GL/ChartFields, assets/projects and other confirmed financial workflows.
- [Campus Solutions](campus-solutions/SKILL.md): admissions/program, enrollment/records, student financials and aid.

These are unfilled LOCAL_TEMPLATE scaffolds. Copy to an approved private location outside this repository. Narrow module scope, fill metadata/evidence, add verified local gotchas and owner-approved synthetic cases, then rename the skill/description and install in the intended host. Use [specialist-building guide](../guide-specialist-trainer/GUIDE.md).

UNCONFIRMED fields and NOT RUN statuses are intentional. Do not turn them into guessed facts. Keep a source ledger and revalidate after releases/configuration/policy changes. The public package includes only these generic templates, never your filled copies.
