# Complete Copilot prompt files

Generated from canonical definitions; edit the source and run npm run generate:agents. Each .prompt.md contains the full workflow, constraints, examples and any required connector contract. There are no paste stubs.

1. Copy selected .prompt.md files into the target PeopleSoft solution's .github/prompts.
2. In Visual Studio Copilot attach via #prompt: or the context picker; use slash invocation where your installed version supports it.
3. Supply your task and scrubbed artifacts. Check that the intended prompt is listed in context/references.
4. Use one specialist at a time; copy its handoff context to the next prompt if needed.

[Microsoft Visual Studio guidance](https://learn.microsoft.com/en-us/visualstudio/ide/copilot-chat-context?view=vs-2022). Host versions/policies affect invocation. These are reusable prompt files, not a claim of custom-agent support in every Copilot host. No model is prescribed. [Pack catalog](../README.md).
