Features

  4. Optional: set Trace presets if you have UTILITIES security
  5. Optional: open the Side Panel from the extension popup

Utilities bar placement

Default sits above the Classic content iframe (or in the Fluid header). Open menus close when you click into the page so they don’t cover Run / Process Scheduler controls.

Field Entry profiles

Named capture/paste profiles used by the Entry bar menu (enable under Optional / careful). Session clipboard is not stored; only named profiles persist here.

Profiles may contain business keys (EmplIDs, department IDs, guest defaults). Treat exports as sensitive.

Customization upgrade watch

Compares page tabs, structure hosts, and field ids vs a baseline you capture before upgrade. Only the current loaded page is captured: up to 200 unique field IDs and 40 structure hosts. Unloaded tabs, PeopleCode, SQL and database changes are not compared — use App Designer Compare Report and your upgrade validation process.

Retains up to five baselines per component/environment and 50 total. Page Info lets you select a dated baseline, compare UI drift and copy a reviewed upgrade handoff.

No baselines yet — open Page Info on a component and choose Capture baseline.

Tracing profiles

Flags applied by an explicit On request from the bar. Requires access to delivered trace components. The bar shows request history, not live server trace status; verify in PeopleSoft.

When to use which flags: Start with SQL Statement + Bind when a page feels slow or returns wrong data — binds show the literal values sent to the database. Add PeopleCode Assignments or Start of programs when a field change, save, or row event looks wrong but SQL is clean. Use Verbose only for short, targeted sessions — it adds a lot of log noise. Turn Trace off when you are done.

Presets

Environments

Name and explicitly classify each environment. Color and names never determine production status. Production keeps the bar at the top of the document and sticky, and confirms MPU Field Entry Apply and trace start; trace stop stays available.

Host allowlist (optional)

Default: MPU runs on any host matching PeopleSoft psp/psc URL patterns. Enable this only if your organization wants a tighter origin list.

When enabled with an empty list, MPU will not inject on any page.
