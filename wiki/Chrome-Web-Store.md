# Chrome Web Store

MPU is built for official Chrome Web Store distribution.

- Listing copy & assets: repository `store/`
- Submission checklist: `store/SUBMISSION_CHECKLIST.md`
- Release readiness: `docs/release-readiness.md`
- Import live screenshots: drop files in `store/assets/screenshots/_inbox/` → `npm run import:store-screenshots`
- Upload zip: GitHub Release **`morris-peoplesoft-utilities-v1.0.26.zip`** (after tag) via Developer Dashboard

After publication, this page should link the live Store URL.
