# Initial store submission assets

Historical initial-listing evidence only: `options-features.png` is an
unaltered 1280 × 800 capture of the actual packaged version 1.0.26 Options UI,
created with `npx tsx scripts/capture-store-options.ts` on 2026-10-12 in a fresh
Chromium profile. It contains no employer or user records.

The current listing captures and their provenance are documented in
`../README.md`. The `../screenshots/` set was subsequently replaced by genuine
1.0.30 Options captures; this historical 1.0.26 image does not replace them.

The store icon and promotional artwork remain in the parent assets directory.
This screenshot is evidence of the extension Options UI, not PeopleTools
compatibility testing. The maintainer confirmed prior testing in the publishing
chat; detailed patch-level results were not supplied.

`chrome-1.0.31-pending-review.png`, `chrome-1.0.32-pending-review.png`, and
`chrome-1.0.33-pending-review.png` preserve the observed dashboard states at
those submission checkpoints. They are not current approval/publication checks.
The account reauthentication capture is private, ignored, and not committed.
