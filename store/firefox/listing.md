# Firefox Add-ons listing

## Name

Morris PeopleSoft Utilities

## Summary

PeopleSoft Classic & Fluid tools: favorites, page info, field inspector and trace. Local settings. No passwords or telemetry.

## Description

Morris PeopleSoft Utilities helps business analysts and technical staff work with Oracle PeopleSoft Classic and Fluid pages.

- Identify environments and explicitly mark production systems.
- Organize favorites and recent component shortcuts; import/export favorites and settings locally.
- View page information, field identities, page structure and read-only Fluid diagnostics.
- Use optional Field Entry to preview and apply values to visible editable fields. Preview does not add rows or save a transaction; normal PeopleSoft validation and save protections still apply.
- Request PeopleCode/SQL trace changes using your existing PeopleSoft permissions. Request evidence does not establish the current server trace state.
- Compare reviewed UI snapshots and supported configuration files locally. These comparisons do not prove server-side or database equivalence.
- Keep environment runbooks and customization upgrade baselines on your device.
- Browse a local catalog of reusable PeopleSoft prompts and prepare an unsaved task brief for your approved AI tool. MPU does not run AI agents or send page data to an AI service.
- Open Favorites, Page Info, Oracle documentation and agent references in Firefox's sidebar or Options.

Settings and saved workspaces remain in this browser profile. No passwords, analytics or developer telemetry. The optional host allowlist limits activation to your chosen PeopleSoft origins. Authenticated feature requests stay on the PeopleSoft origin you are already using. External documentation and saved links open only when selected.

Firefox desktop 140 or newer. PeopleTools 8.62 is the compatibility target; synthetic tests and screenshots are not Oracle patch-level certification. Requires access to your organization's PeopleSoft system for page features. No account is required for the extension itself.

Designed toward WCAG 2.1 AA for extension UI; automated accessibility checks do not establish conformance.

Maintained by hackmods (Ryan Morris). Inspired by PS Utilities (Uffe Graakjaer, Neil Yetman, and contributors). MIT licensed.
